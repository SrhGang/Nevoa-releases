# Névoa — Releases

Ce repo contient les releases APK de l'application Android **Névoa**.

Le fichier [`latest.json`](./latest.json) est mis à jour automatiquement à chaque nouvelle release.

## Télécharger la dernière version

1. Consultez [`latest.json`](./latest.json) pour connaître la version courante
2. Téléchargez directement l'APK via le `downloadUrl` présent dans ce fichier
3. Ou rendez-vous dans l'onglet [Releases](https://github.com/SrhGang/Nevoa-releases/releases)
